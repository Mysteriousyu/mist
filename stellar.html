Some sites can't load inside Stellar

Sites like Google, Gmail, YouTube and banking apps refuse to run in embedded browsers for security. This is a browser rule Stellar can't override.

Try opening this site in a new window instead: Open externally →

Search engines like DuckDuckGo work inside Stellar. So do most content sites.
